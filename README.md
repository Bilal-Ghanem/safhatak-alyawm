# Same-day landing page offer

Arabic sales page for a SAR 299 one-page website service, with a 24-hour delivery promise beginning only after client materials are received.

Before publishing, inject the approved WhatsApp URL as a base64 value into the `<html>` element:

```html
<html lang="ar" dir="rtl" data-contact="BASE64_VALUE">
```

The page deliberately does not claim a portfolio, buyer count, scarcity, guaranteed results, domain, hosting, ecommerce, or payment capability.
